# Insert In Style Bench: image sources

788 pairs over 51 backgrounds and 25 foregrounds. Paths are relative to `benchmark/`. BibTeX keys refer to [`sources.bib`](sources.bib); the same keys are used in the paper (Supp. Sec. *Insert In Style Bench Details*).

## What we distribute

Like LAION, we only distribute what is ours and point to everything else:

- **In this folder (git):** the pair JSONs, every mask (background insertion regions and subject masks) and the 18 images we generated with Gemini 2.5.
- **Not distributed:** the 57 third-party images. [`image_sources.csv`](image_sources.csv) lists each one with its source URL, the path inside the source dataset, the crop box and output size we used, its licence and a checksum. [`retrieve_images.py`](retrieve_images.py) downloads and rebuilds them (see the [README](README.md#getting-the-images)). The per-image table is in [`IMAGES.md`](IMAGES.md).

Third-party images keep their original licences; check them before any use beyond research evaluation.

## How the images were matched to their sources

- **Human-Art:** file name and md5 match the Human-Art release (`images/2D_virtual_human/<cartoon|digital_art>/`).
- **WikiArt:** each painting was found on wikiart.org and verified visually. Our copies are square crops, resized to 1382 px. wikiart.org may serve a different scan today, so a rebuilt image can differ slightly at pixel level; the check uses a perceptual hash.
- **Kaggle:** 4 files are byte-identical to the Kaggle file; 8 are square crops of one, pixel-exact up to JPEG re-encoding (≥ 40 dB).
- **DreamBooth:** each cut-out is a crop of one subject photo (pinned to commit `4f887af`) with our segmentation as alpha.
- **Gemini:** XMP metadata "Edited with Google AI".
